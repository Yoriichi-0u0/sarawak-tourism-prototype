# Image generation prompt set

All assets were generated with the built-in imagegen tool. No fallback API/CLI mode was used. Final optimized assets are in `public/images/`, with filenames corresponding to the headings below. These are illustrative concept images, not documentary photographs or verified representations of specific properties.

The full desktop/mobile working concept is stored in `docs/design-concept.png`. Its design brief requested a Sarawak travel guide with a white background, pine-green controls, editorial serif headings, the specified navigation and discovery copy, a rainforest river hero, a single search band, interest filters, three leading photo cards, and a mobile bottom navigation. It also described the required detail, stay, food, transport, itinerary, and management states. See `docs/design.md` for the extracted specification and intentional deviations.
