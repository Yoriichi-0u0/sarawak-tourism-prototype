## Visitor workflow

Browse a category → search/filter → inspect details → optionally compare → save or add to trip → arrange days/notes → export or share. Visitors may browse without creating a trip. A no-results state supports revising the search. External provider visits do not imply booking confirmation.

## Management demo workflow

Enter the clearly labelled demo → review/search listings → create or edit → validate → publish → inspect the public catalogue in the same browser. Archive removes a listing from discovery while preserving it for restoration. Reports reflect only local actions. Reset explicitly confirms replacement of local demo data.
